📊 Stack Overflow Developer Survey Analysis (2023-2025)
Part 1: The Education & Career Trajectory🎯 
Project Overview:
This project is a longitudinal study of the Stack Overflow Developer Survey data across three years (2023-2025).
It aims to uncover the evolving relationship between educational backgrounds, compensation trends, and learning habits in a
rapidly changing tech landscape influenced by AI.💡
Key Insights (Education Section):
Through rigorous data cleaning and quantitative analysis using Python, the following insights were discovered: 
1- The Academic Premium: PhD holders experienced a robust 12% salary growth, contrasting with a 2% decline for undergraduate
certificate holders between 2023 and 2025.
2- Documentation Over Hype: Despite the meteoric rise of generative AI tools, Technical Documentation remains the #1 resource
for developers globally, proving that foundational knowledge is still king.
3- Python’s Academic Dominance: There is a strong correlation between advanced academia and language choice; PhD holders 
represent the highest educational group utilizing Python (12.7%).
🛠️ Tech Stack
Language: Python 
Libraries: Pandas (Data Wrangling), Matplotlib & Seaborn (Statistical Visualization) 
Analysis Method: Longitudinal Trend Analysis & Correlation Mapping
